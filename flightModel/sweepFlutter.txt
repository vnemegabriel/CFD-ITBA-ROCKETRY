# One run per line:  <name> <newCase.sh options>.  Blank lines and # are ignored.
# Same format as sweepSupersonic.txt:
#
#     ./runCase.sh [--np <N>] [--socket <S>] sweepFlutter.txt [runs-dir] [meshes-dir]
#
# Without --np each case takes every physical core of the computer (or of
# --socket).  runCase.sh --np sets it for the file; --np on a line, for that run.
#
# Base flows of the fin flutter analysis (fin_flutter/docs/PROCEDURE.md, step 5),
# alpha 0, h0: the Mach numbers that sweepSupersonic.txt does not have.  With
# m12-a00-h0 and m18-a00-h0 they give M 1.05 1.1 1.2 1.3 1.4 1.6 1.8 1.86.
# The forced runs start from the pimple run of each Mach (sweepFlutterForced.txt).
#
# pInf and Tinf: the atmosphere of the flight at the height where the vehicle
# passed each Mach number in the coast (flightData/cdFlight.py); M 1.86 is the
# maximum, t 3.54 s, end of the burn.
#   M     t [s]  h pad [m]
#   1.05   9.98   4016
#   1.1    9.44   3826
#   1.3    7.56   3084
#   1.4    6.75   2719
#   1.6    5.32   2001
#   1.86   3.54    950
