# One run per line:  <name> <newCase.sh options>.  Blank lines and # are ignored.
# --mesh names a mesh in <meshes-dir> (build it first with runMesh.sh), and
# --init a run in <runs-dir> that comes earlier in this file.
#
#     ./runCase.sh [--np <N>] sweepPimple.txt [runs-dir] [meshes-dir]
#
# Without --np each case takes every physical core of the computer.
# runCase.sh --np sets it for the file; --np on a line, for that run.
#
# The whole sweep in one file: M 0.3 to 1.8, alpha 0 and 2 deg, meshes h0 to h3,
# all with rhoPimpleFoam (docs/guide, Two solvers).  sweepSubsonic.txt and
# sweepSupersonic.txt have the same conditions, divided for a computer with two
# sockets; there each mesh starts from the mesh before it.
#
# h0 starts from a uniform free stream.  h1, h2 and h3 each start from the h0 run
# of the same Mach number and angle (--init).
# --alpha turns the free stream in the x-y plane; the mesh does not change.
# M 1.0 keeps the subsonic boundary conditions: 0.orig/p sets the supersonic ones
# for Minf > 1 only.
#
# pInf and Tinf: the atmosphere of the flight at the height where the vehicle
# passed each Mach number in the coast (flightData/cdFlight.py prints them).
