\chapter{Validation}\label{ch:validation}

This chapter gives the procedures that compare the results with references. Each
reference has its formula and its constants, so that you can calculate it by hand.
Do the procedures in this sequence:

\begin{steps}
\item The checks of \cref{sec:run-checks}, on each run.
\item Subsonic flow (\cref{sec:barrowman}). There are analytical references.
\item Transonic and supersonic flow (\cref{sec:supersonic-validation}).
\item The flight (\cref{ch:flight}).
\item Mesh convergence (\cref{sec:gci}), before you publish a value.
\end{steps}

\section{Subsonic flow: Barrowman}\label{sec:barrowman}

The references are the equations of \citet{barrowman1967,barrowman1966}, which
OpenRocket uses. \citet[ch.~2]{fleeman2012} gives equivalent equations for the fins
and the fin-body interference. The coefficients refer to the body cross-section
$A = \pi d^2/4$ and are for each radian.

\subsection{Procedure}

\begin{steps}
\item Run an angle-of-attack sweep from $0^\circ$ to $6^\circ$.
\item Calculate the slope of $C_N$ against $\alpha$ in radians. Use the force normal
  to the body axis, not $C_L$: $C_L$ is normal to the free stream,
  $C_N = C_L\cos\alpha + C_D\sin\alpha$.
\item Compare the slope with the sum of the components.
\item For the breakdown, add one \ent{forceCoeffs} function object for each patch and
  compare each term with its reference.
\end{steps}

\section{Transonic and supersonic flow}\label{sec:supersonic-validation}

No analytical reference applies to the full rocket. Use these methods, from the
smallest to the largest work.

\begin{enumerate}
\item \textbf{Tutorial of the template.} Run
  \file{$FOAM_TUTORIALS/compressible/rhoCentralFoam/biconic25-55Run35} and compare it
  with its published data. This validates the solver and the flux scheme, and
  separates a configuration error from a mesh error.
\item \textbf{Oblique shock on a wedge.} The $\theta$--$\beta$--$M$ relation is exact
  \citep[ch.~4]{anderson2003}:
  \[
    \tan\theta = 2\cot\beta\,\frac{M^2\sin^2\beta - 1}{M^2(\gamma + \cos 2\beta) + 2}.
  \]
  The tutorial \file{rhoCentralFoam/wedge15Ma5} is this case. Compare the shock angle
  and the pressure ratio.
\item \textbf{Flight.} \Cref{ch:flight}. The flight $C_D$ rises from 0.31 at $M = 0.9$
  to approximately 0.70 at $M = 1.03$, and decreases to 0.39 at $M = 1.8$. The CFD
  must show this rise. If it does not, the mesh is too coarse where the shock occurs.
\item \textbf{OpenRocket.} Semi-empirical. It finds an error of a factor of 2. It does
  not support a difference of 5\,\%, and it does not show the transonic peak of the
  flight.
\end{enumerate}

\section{Mesh convergence}\label{sec:gci}

\subsection{Procedure}

\begin{steps}
\item Make three meshes with only \ent{maxCellSize} changed (\cref{sec:mesh-convergence-setup}).
\item Run the same flight condition on the three meshes.
\item Measure \yplus{} on each mesh. It must stay in the same range.
\item Calculate the representative cell size $h = N^{-1/3}$ of each mesh, and the
  ratio of each pair, $r = h_\text{coarse}/h_\text{fine}$.
\item Calculate the observed order $p$, the extrapolated value and the grid
  convergence index with the method of \citet{celik2008}.
\end{steps}

\subsection{Equations}

With $f_1$, $f_2$, $f_3$ the results on the fine, the medium and the coarse mesh, and
a constant ratio $r$:
\[
  p = \frac{\ln\left[(f_3 - f_2)/(f_2 - f_1)\right]}{\ln r}, \qquad
  f_\text{ext} = f_1 + \frac{f_1 - f_2}{r^p - 1}, \qquad
  \text{GCI}_{12} = 1.25\,\frac{|(f_1 - f_2)/f_1|}{r^p - 1}.
\]
The ratios of the sweep meshes are not equal (1.25 and 1.33,
\cref{sec:mesh-convergence-setup}). Use the iterative form of \citet{celik2008} for
unequal ratios. If $(f_3 - f_2)/(f_2 - f_1)$ is negative, the convergence is
oscillatory and the equations do not apply \citep{roache1994}.
