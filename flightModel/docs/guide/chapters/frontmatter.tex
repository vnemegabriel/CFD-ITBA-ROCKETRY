\section*{Maintenance of this document}

\begin{itemize}
\item This guide is the only user documentation of \file{flightModel/}. The
  dictionaries and scripts are the only source of the parameter values: this guide
  tells where each value is, and why, but does not copy it.
\item When a change to a script changes a procedure, change the guide in the same
  commit. Compile it with \cmd{make} (\cref{sec:build-guide}) and commit the PDF.
\item Results go to the technical report, not to this guide.
\end{itemize}

\section*{Purpose}

This guide tells you how to calculate the drag coefficient of a finned rocket as a
function of the Mach number and the angle of attack with OpenFOAM, how to estimate the
discretization error, and how to compare the result with flight data and with another
solver. For each step it gives the procedure and the principle that justifies it.

\section*{Audience}

Engineering students and engineers who replicate or extend the workflow, on any
computer. You need a basic course of fluid mechanics and the use of a command line.
\Cref{ch:concepts} gives the CFD concepts that the workflow uses and a learning path
for a reader with little CFD practice.

\section*{Scope}

The directory \file{flightModel/}: geometry, mesh, case templates, sweeps,
post-processing, measurement of the computer and flight data. The guide applies to
any computer: with the container on Windows, macOS or Linux, or with a native
installation on Linux (\cref{sec:install}).

\section*{Writing standard}

The structure follows ISO/IEC/IEEE 26514 \citep{iso26514}: concepts, procedures and
reference information are separate. The text follows the rules of ASD-STE100
Simplified Technical English \citep{asdste100}. Technical names stay as the OpenFOAM
documentation writes them.
