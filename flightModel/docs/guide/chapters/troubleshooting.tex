\section{mapFields stops with a segmentation fault}\label{sec:ts-mapfields}

\cmd{mapFields -consistent} of OpenFOAM v2412 can stop with a segmentation fault right
after \val{interpolating Ma}. The cause is a null-pointer read in
\ent{meshToMesh0::calculateInverseDistanceWeights()}: when the centre of a target cell
is within 1e-5~m of a neighbour of its nearest source cell, the function leaves the
list of weights of that cell empty. The fault depends on the pair of meshes. It
occurred from $h_1$ to $h_2$ and not from $h_0$ to $h_1$ or from $h_0$ to $h_2$.
\file{Allrun} stops the run if the log of \cmd{mapFields} or \cmd{changeDictionary}
does not end with \val{End}; a check for \val{FOAM FATAL} only does not detect a
segmentation fault.

Two remedies are available:

\begin{itemize}
\item Start the finer mesh from the $h_0$ run. This needs no change, but the start
  solution is worse.
\item Use a \cmd{mapFields} with the corrected function. Put it first in \ent{PATH}
  for the sweep that needs it (\cref{sec:sweep-pimple}). The \cmd{mapFields} of the
  system does not change.
\end{itemize}

\section{The Courant number with a local time step}\label{sec:ts-courant}

With \ent{localEuler}, \cmd{rhoCentralFoam} calculates the Courant number with the
global \ent{deltaT}, so the value in the log is meaningless. Read
\val{Flow time scale min/max} (\cref{sec:lts}).

\section{Decimal comma}\label{sec:ts-locale}

In a locale with a decimal comma, \cmd{awk} reads and writes numbers with a comma, and
OpenFOAM reads them incorrectly. Each script that calculates with \cmd{awk} sets
\cmd{LC_ALL=C}. Do the same in a new script.

\section{Rules for a change to the scripts}

\begin{itemize}
\item Measure before you propose a change; a change without a number is not complete.
\item Do not put a Python script in a bash here-document: a \texttt{\textbackslash n}
  in an f-string becomes a real new line and breaks the file.
\item After a change, run one short case and examine \file{run.info}.
\item Change this guide in the same commit.
\end{itemize}
