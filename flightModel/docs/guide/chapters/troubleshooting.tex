The run stopped at iteration 584 because the computer stopped, not the solver. The
wall shear stress increases by a factor of 3. The flight gives $C_D = 0.39$ at this
Mach number. Items to examine:
\begin{itemize}
\item The wall conditions and the wall functions of the two templates (\ent{nut},
  \ent{k}, \ent{omega}, \ent{T}, \ent{alphat}).
\item The transfer of the fields with \cmd{mapFields} and \cmd{changeDictionary},
  including the turbulence fields.
\item The flux scheme and the limiter at the wall.
\item The difference between the start transient and the steady state.
\end{itemize}

\section{mapFields on the same mesh}\label{sec:ts-mapfields}

\textbf{Symptom.} \cmd{mapFields} stops with a segmentation fault at the field
\ent{Ma}, when the source and the target are the same mesh ($h0 \to h0$, 2026-10-17).
Between different meshes ($h0 \to h1$) it works.

\textbf{Effect before the correction.} \file{Allrun} looked only for \val{FOAM FATAL}.
The run started from the uniform free stream, and the log said that the mapping was
correct.

\textbf{Current behaviour.} \file{Allrun} stops if the log of \cmd{mapFields} or
\cmd{changeDictionary} does not end with \val{End}.

\textbf{Open item.} The cause of the fault is not known. The supersonic chain needs
this mapping (pimple $\to$ central on $h0$). On the same mesh, a copy of the fields
of the source run is an alternative that does not interpolate.

\section{The Courant number in the log}\label{sec:ts-courant}

With \ent{localEuler}, \cmd{rhoCentralFoam} calculates the Courant number with
\ent{deltaT 1} of \file{controlDict}, so it writes values of approximately $10^7$.
\cmd{rhoPimpleFoam} does not write it. Read \val{Flow time scale min/max}. This
incorrect reading kept the central template on a global \ent{Euler} step until
2026-10-12.

\section{Decimal comma in scripts}\label{sec:ts-locale}

With the locale \texttt{es\_ES} (\texttt{newton}), \cmd{awk} reads and writes numbers
with a decimal comma. \file{Allmesh} once gave \val{11,775} to
\cmd{surfaceGenerateBoundingBox} and made an incorrect domain. Each script that
calculates with \cmd{awk} sets \cmd{LC_ALL=C}: \file{Allmesh}, \file{Allrun} and the
calculation of the block \ent{flow} in \file{newCase.sh}. Do the same in a new script.

\section{Rules for a change to the scripts}

\begin{itemize}
\item Measure before you propose a change. A change without a number is not complete.
\item Do not put a Python script in a bash here-document: a \texttt{\textbackslash n}
  in an f-string becomes a real new line and breaks the file.
\item After a change to a script, run one short case and examine \file{run.info}.
\item Change this guide in the same commit.
\end{itemize}
