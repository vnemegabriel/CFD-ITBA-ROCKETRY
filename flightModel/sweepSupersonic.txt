# One run per line:  <name> <newCase.sh options>.  Blank lines and # are ignored.
# --mesh names a mesh in <meshes-dir> (build it first with runMesh.sh), and
# --init a run in <runs-dir> that comes earlier in this file.
#
#     ./runCase.sh [--np <N>] [--socket <S>] sweepSupersonic.txt [runs-dir] [meshes-dir]
#
# The number of processes and the socket are options of runCase.sh, not of
# the lines, so the file is the same on every computer.
# M 1.2 and 1.8 here; sweepSubsonic.txt has the other Mach numbers.  On a computer with
# two sockets, run one file on each socket (--socket 0, --socket 1).
#
# Each Mach number and angle of attack is a chain h0 -> h1 -> h2 -> h3, each
# run started from the previous one (--init).  h0 only starts the chains.
# --alpha turns the free stream in the x-y plane; the mesh does not change.
# M < 1 runs rhoPimpleFoam.  M > 1 runs rhoCentralFoam, started on h0 from a
# rhoPimpleFoam run at the same Mach (docs/guide, Start of the supersonic cases).
#
# pInf and Tinf: the atmosphere of the flight at the height where the vehicle
# passed each Mach number in the coast (flightData/cdFlight.py prints them).
