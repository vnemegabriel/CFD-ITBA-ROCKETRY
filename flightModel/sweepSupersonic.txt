# One run per line:  <name> <newCase.sh options>
# --mesh names the mesh (a bare name lives in ~/meshes); build it first with
# ./runMesh.sh (meshes.txt).  Blank lines and # are ignored.
# ./runCase.sh runs them in series, on socket 0 with 14 processes.
# M 1.2 and 1.8.  sweepSubsonic.txt has M < 1 on socket 1; run both at once.
#
# Each Mach number and angle of attack (0, 4, 8 deg) is a chain
# h0 -> h1 -> h2 -> h3, each run started from the previous one (--init,
# mapFields).  h0 is not part of the mesh study.  --alpha turns the free
# stream in the x-y plane; the mesh does not change.
# M < 1 runs rhoPimpleFoam.  M > 1 runs rhoCentralFoam, started on h0 from a
# rhoPimpleFoam run at the same Mach: from the uniform free stream the base
# wake empties and rhoCentralFoam crashes (docs/SOLVERS.md section 17).
#
# Coast, t > 4 s: pInf and Tinf are ISA at the altitude where the TeleMega
# passes each Mach (pad 896 m MSL).
#   M 1.8  t  4.0 s  1936 m      M 0.8  t 13.5 s  5604 m      M 0.3  t 26.5 s  7901 m
#   M 1.2  t  8.2 s  3913 m      M 0.6  t 18.3 s  6710 m
